# FLARE NUINUI QUEST Archipelago Setup Guide

## Required Software

- Hololive Treasure Mountain from: [Steam](https://store.steampowered.com/app/3081830)
- NuinuiMods from: [NuinuiMods releases page](https://github.com/StellatedCUBE/NuinuiMods/releases)
- Archipelago mod for FLARE NUINUI QUEST from: [NuinuiArchipelago releases page](https://github.com/StellatedCUBE/NuinuiArchipelago/releases)

## Installation Procedure

- Install NuinuiMods by following [the directions on the NuinuiMods GitHub page](https://github.com/StellatedCUBE/NuinuiMods#installation).
- Place `NuinuiArchipelago.asar` inside your NuinuiMods folder.

## Connecting

Select “ARCHIPELAGO” on the main menu (typically between “ARCADE” and “OPTIONS”) and enter your room's connection details.

## Resuming

Connecting to the same game, even if it's at a different address, will load the correct save file.
